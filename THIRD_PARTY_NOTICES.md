# Источники приложений и авторство

Публичный набор переиспользует официальные **неизменённые** APK соответствующих upstream-проектов. Репозиторий содержит ссылки на исходные релизы, контрольные суммы и собственные вспомогательные скрипты.

| Компонент | Исходники | Указанная лицензия |
| --- | --- | --- |
| CVE-2026-98260 Root App | https://github.com/woshigenm/CVE-2026-98260 | MIT |
| KernelSU | https://github.com/tiann/KernelSU | GPL-2.0 |
| KernelSU Next | https://github.com/KernelSU-Next/KernelSU-Next | GPL-2.0 |
| Shizuku | https://github.com/RikkaApps/Shizuku | Apache-2.0 |
| Shizuku+ Drop-In | https://github.com/thejaustin/ShizukuPlus | Apache-2.0 |
| aShell You | https://github.com/DP-Hridayan/aShellYou | GPL-3.0 |

Точные версии, SHA-256 и URL всех APK: [apps/manifest.json](apps/manifest.json). Собственные файлы репозитория — [MIT](LICENSE). Права на сторонние приложения остаются за их авторами, а их лицензии приведены в исходных репозиториях.
