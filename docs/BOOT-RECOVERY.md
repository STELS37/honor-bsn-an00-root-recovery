# После перезагрузки

Состояние автоматически восстановленного root на HONOR BSN-AN00 пока не подтверждено. На этом устройстве установлен временно загружаемый модуль KernelSU, который исчезает после перезагрузки.

Проверенный ручной порядок работы, версии приложений и исходники описаны в [README](../README.md). Закреплённые официальные загрузки APK и контрольные суммы собраны в [манифесте](../apps/manifest.json).

Автоматический запуск Shizuku через Wireless Debugging исследуется отдельно от загрузки KernelSU. Корректный признак успешного восстановления — не иконка приложения, а состояние модуля ядра и проверенные права root.
