# Архитектура временного root

На HONOR BSN-AN00 был использован публичный исследовательский проект [CVE-2026-98260](https://github.com/woshigenm/CVE-2026-98260). Уязвимость класса **use-after-free** затрагивает работу POSIX CPU-таймеров ядра. В проверенном сценарии локальный процесс Shell получил расширенные полномочия, после чего в работающее ядро был загружен модуль KernelSU.

Последовательность наблюдений: запуск из контекста Shell / Shizuku (UID 2000); успешная работа цепочки по журналу; получение UID 0; появление модуля KernelSU; установка его пользовательской части. После перезагрузки модуль исчезал из оперативной памяти — это ожидаемое свойство временной загрузки, а не доказательство повреждения прошивки.

**Зафиксированные маркеры:** `KSU_CHAIN_OK`, `GRANT_ROOT rc=0 uid=0`, `ROOT_STAGE_OK`, `DONE`. При этом `PARKED=1` указывает на удерживаемые эксплуатационной процедурой процессы. Признаки следует интерпретировать в совокупности, а не по одной строке.

Непосредственный первоисточник с кодом, анализом ядра и условиями поддержки конкретного kernel release: [woshigenm/CVE-2026-98260](https://github.com/woshigenm/CVE-2026-98260/blob/main/README.md). В этой папке фиксируется именно наблюдаемый результат для модели BSN-AN00, без подмены гипотез проверенными фактами.
